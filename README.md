# GreenBox 🌿

Андроид-приложение «всё в одном»: **фоторедактор с большим набором инструментов + 6 мини-игр + настройки**.
Написано полностью на **Kotlin**. Собирается автоматически через **GitHub Actions** — APK можно скачать прямо из репозитория.

## Настройки (v2.0)

- Тема: системная / светлая / тёмная
- Качество сохранения JPEG (50–100 %)
- Максимальный размер открываемого фото (1200 / 1600 / 2400 px)
- Толщина и цвет кисти по умолчанию
- Водяной знак GreenBox на сохраняемых фото
- Сетка в играх, вибрация, сброс настроек

## Новый логотип

Старый символ перерисован: зелёная иконка с волнистым медальоном и новым знаком
«диафрагма + play» (камера и игры в одном символе).

- `logo.svg` — вектор
- `logo.png` — PNG 1024×1024
- `tools/make_logo.py` — генератор логотипа и иконок для всех плотностей экрана

Перегенерировать иконки:

```bash
pip install pillow
python3 tools/make_logo.py
```

## Что умеет фоторедактор

- Открыть фото из галереи или сделать снимок камерой
- 15 фильтров: оригинал, ч/б, сепия, негатив, холодный, тёплый, винтаж,
  нуар, неон, пастель, закат, аква, резкость, размытие, эмбос
- Настройки: яркость, контраст, насыщенность (с предпросмотром)
- Поворот на 90°, отражение по горизонтали и вертикали
- Обрезка по соотношениям 1:1, 4:3, 16:9
- Рисование пальцем: 6 цветов, кисть, очистка
- Текст с выбором цвета и автоматическим масштабированием
- Стикеры-эмодзи (16 штук) в случайном месте
- Отмена / повтор (история до 20 шагов)
- Сохранение в галерею и отправка «Поделиться»

## Игры

1. 🐍 Змейка — свайпы или кнопки, счёт, стена и столкновения
2. 🔢 2048 — классическая сливающаяся головоломка
3. ❌⭕ Крестики-нолики — ИИ с минимаксом, счёт побед
4. 🧠 Память — 8 пар карточек, счёт ходов
5. 🎲 Кубики — от 1 до 6 кубиков с анимацией и суммой
6. ⚡ Реакция — замер времени реакции и личный рекорд

## Сборка APK через GitHub Actions

1. В репозитории откройте вкладку **Actions**
2. Выберите workflow **Build APK** → **Run workflow**
3. После завершения откройте последний запуск и скачайте артефакт
   **GreenBox-debug** (или **GreenBox-release-unsigned**)
4. Распакуйте ZIP, доставьте `app-debug.apk` на телефон и установите

Автосборка также запускается при каждом `push` и `pull request`.
Если запушить тег вида `v1.0`, APK ещё и прикрепится к **Release**.

Локально (нужны JDK 17 и Android SDK 34):

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Техническое

- Kotlin 2.0.20 + AndroidX AppCompat / Material / Coroutines (APK ~3–4 МБ)
- `minSdk 21` (Android 5.0), `targetSdk 34`
- Gradle 8.7 wrapper, Android Gradle Plugin 8.5.2
- Сборка в `ubuntu-latest`: JDK 17 + Android SDK + Gradle
